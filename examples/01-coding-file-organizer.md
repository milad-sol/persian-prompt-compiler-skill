# مثال ۱: کدنویسی با محدودیت منفی

نشان می‌دهد اسکیل چطور «نکن»ها را با همان قاطعیت حفظ می‌کند و چیزی به استک اضافه نمی‌کند.

## ورودی

```
این رو پرامپت کن: یه اسکریپت پایتون بنویس که فایل‌های یه پوشه رو بر اساس پسوندشون توی پوشه‌های جدا بریزه. از کتابخونه‌ی خارجی استفاده نکن. فایل‌های مخفی رو دست نزن.
```

## خروجی

**دسته:** coding / scripting - اسکریپت پایتون برای مرتب‌سازی فایل‌ها بر اساس پسوند

**پرامپت انگلیسی:**
```
Write a Python script that organizes the files in a given folder into subfolders based on their file extension.

Requirements:
- Move each file into a subfolder named after its extension.
- Leave hidden files untouched.

Constraints:
- Use only the Python standard library. Do not use any external libraries.
```

**ترجمه فارسی (برای بررسی):**
```
یک اسکریپت پایتون بنویس که فایل‌های یک پوشه‌ی مشخص را بر اساس پسوندشان در زیرپوشه‌ها مرتب کند.

نیازمندی‌ها:
- هر فایل را به زیرپوشه‌ای با نام پسوندش منتقل کن.
- به فایل‌های مخفی دست نزن.

محدودیت‌ها:
- فقط از کتابخانه‌ی استاندارد پایتون استفاده کن. از هیچ کتابخانه‌ی خارجی استفاده نکن.
```

- **الزامات حفظ‌شده**
  - پایتون
  - مرتب‌سازی بر اساس پسوند در پوشه‌های جدا
  - بدون کتابخانه‌ی خارجی
  - فایل‌های مخفی دست‌نخورده بمانند
- **اطلاعات ناقص**
  - فایل‌های بدون پسوند کجا بروند؟
  - مسیر پوشه از کجا گرفته شود (آرگومان خط فرمان یا مسیر ثابت)؟
- **پیشنهادهای اختیاری**
  - حالت آزمایشی (dry run) که قبل از جابه‌جایی، فقط تغییرات را نشان دهد.

اجراش کنم؟

## چه چیزی اضافه نشد

اسکیل سرخود `argparse`، لاگ‌گیری، تست یا رابط گرافیکی را به‌عنوان الزام اضافه نکرد. «حالت آزمایشی» فقط پیشنهاد است و داخل پرامپت نیامده.
