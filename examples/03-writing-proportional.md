# مثال ۳: درخواست ساده و اصل تناسب

درخواست ساده، پرامپت کوتاه می‌گیرد؛ نه یک سند چندبخشی.

## ورودی

```
پرامپت کن: این متن رو رسمی‌تر کن، برای ایمیل به استادمه:
سلام استاد، ببخشید دیر شد پروژه، تا پنجشنبه می‌فرستم حتماً.
```

## خروجی

**دسته:** writing / editing - رسمی کردن یک ایمیل کوتاه به استاد

**پرامپت انگلیسی:**
```
Rewrite the following Persian text in a formal, polite tone suitable for an email to a university professor. Keep the meaning unchanged and write the result in Persian.

Text:
سلام استاد، ببخشید دیر شد پروژه، تا پنجشنبه می‌فرستم حتماً.
```

**ترجمه فارسی (برای بررسی):**
```
متن فارسی زیر را با لحنی رسمی و مؤدبانه، مناسب ایمیل به استاد دانشگاه، بازنویسی کن. معنا را تغییر نده و نتیجه را به فارسی بنویس.

متن:
سلام استاد، ببخشید دیر شد پروژه، تا پنجشنبه می‌فرستم حتماً.
```

اجراش کنم؟

## چه چیزی اضافه نشد

بخش‌های «زمینه»، «مخاطب هدف»، «تعداد کلمات» یا فهرست اطلاعات ناقص. درخواست به‌اندازه‌ی کافی روشن بود.
