# مثال ۲: درخواست مبهم و پرسیدن قبل از حدس زدن

وقتی اطلاعات کلیدی کم است، اسکیل به‌جای اختراع استک، چند سؤال کوتاه می‌پرسد.

## ورودی

```
پرامپت کن: یه سایت شبیه دیوار می‌خوام
```

## خروجی (مرحله‌ی اول: سؤال)

قبل از ساختن پرامپت، سه چیز مهم را باید بدانم:

۱. با چه زبان یا فریم‌ورکی؟ (یا انتخاب را به ایجنت بسپارم؟)
۲. کدام قابلیت‌ها برای نسخه‌ی اول لازم است؟ مثلاً ثبت آگهی، جستجو، دسته‌بندی، ثبت‌نام، چت.
۳. پروژه‌ی جدید است یا روی کد موجودی ساخته می‌شود؟

## ورودی دوم

```
با جنگو، پروژه جدیده. فقط ثبت آگهی با عکس و جستجو و دسته‌بندی. فعلاً ثبت‌نام نمی‌خوام.
```

## خروجی (مرحله‌ی دوم: پرامپت)

**دسته:** coding / web_development - ساخت نسخه‌ی اولیه‌ی سایت آگهی شبیه دیوار با جنگو

**پرامپت انگلیسی:**
```
Build a new classified-ads website, similar in concept to Divar, using Django.

Scope (first version):
- Users can post an ad with images.
- Ads are organized into categories.
- Users can search ads.

Constraints:
- Do not implement user registration or authentication in this version.
- Do not add features beyond the scope above.
```

**ترجمه فارسی (برای بررسی):**
```
یک وب‌سایت جدید آگهی‌های طبقه‌بندی‌شده، از نظر مفهومی شبیه دیوار، با Django بساز.

محدوده (نسخه‌ی اول):
- کاربران بتوانند آگهی همراه با عکس ثبت کنند.
- آگهی‌ها در دسته‌بندی‌ها مرتب شوند.
- کاربران بتوانند آگهی‌ها را جستجو کنند.

محدودیت‌ها:
- در این نسخه ثبت‌نام یا احراز هویت کاربر را پیاده‌سازی نکن.
- قابلیتی خارج از محدوده‌ی بالا اضافه نکن.
```

- **فرض‌ها**
  - بدون ثبت‌نام، هر بازدیدکننده می‌تواند آگهی ثبت کند.
- **اطلاعات ناقص**
  - دیتابیس مشخص نشده؛ ایجنت از پیش‌فرض پروژه‌ی جنگو استفاده می‌کند.

اجراش کنم؟

## چه چیزی اضافه نشد

PostgreSQL، Docker، React، چت، پرداخت و پنل مدیریت؛ هیچ‌کدام خواسته نشده بود.
