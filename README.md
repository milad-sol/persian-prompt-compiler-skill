# Persian Prompt Compiler Skill

اسکیل Claude برای تبدیل درخواست‌های فارسیِ محاوره‌ای به پرامپت‌های انگلیسی دقیق و قابل اجرا برای Claude Code و ایجنت‌های دیگر، بدون اختراع نیازمندی‌های اضافه.

A Claude skill that compiles casual Persian/Farsi requests into precise, executable English prompts for Claude Code and other AI agents, without inventing requirements.

## چه کاری می‌کند

- قصد کاربر را می‌فهمد، نیازمندی‌ها و محدودیت‌ها را استخراج و دسته‌بندی می‌کند.
- هیچ تکنولوژی، کتابخانه یا ویژگی‌ای را که خواسته نشده اضافه نمی‌کند.
- دستورهای منفی («از Docker استفاده نکن») را با همان قاطعیت حفظ می‌کند.
- اگر اطلاعات مهمی کم باشد، قبل از ساختن پرامپت حداکثر ۳ سؤال کوتاه می‌پرسد.
- پرامپت انگلیسی را همراه با ترجمه‌ی فارسی دقیقش می‌دهد تا بتوانی بررسی‌اش کنی.
- فرض‌ها، اطلاعات ناقص و پیشنهادها را جدا از متن پرامپت نشان می‌دهد.
- طول پرامپت را متناسب با پیچیدگی درخواست نگه می‌دارد.

## نصب

### Claude.ai

1. پوشه‌ی `persian-prompt-compiler` را به‌صورت فایل ZIP فشرده کن.
2. در Claude.ai به Settings > Capabilities > Skills برو و فایل ZIP را آپلود کن.

### Claude Code

پوشه را در مسیر skillهای شخصی یا پروژه کپی کن:

```bash
# برای همه‌ی پروژه‌ها
cp -r persian-prompt-compiler ~/.claude/skills/

# فقط برای یک پروژه
cp -r persian-prompt-compiler .claude/skills/
```

## استفاده

کافی است درخواستت را به فارسی بنویسی و بخواهی پرامپتش کند:

```
این رو پرامپت کن: یه اسکریپت پایتون بنویس که فایل‌های یک پوشه رو بر اساس پسوند دسته‌بندی کنه. از کتابخونه‌ی خارجی استفاده نکن.
```

در Claude Code بعد از دیدن پرامپت می‌توانی بگویی «اجراش کن» تا همان پرامپت به‌عنوان تسک اجرا شود. اگر خروجی JSON بخواهی، کافی است بگویی.
